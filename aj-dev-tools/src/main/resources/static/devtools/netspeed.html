关于限速算法

令牌桶算法原理

  • • 桶容量：允许的突发流量上限
  • • 填充速率：长期平均传输速度
  • • 分块大小：影响流量平滑度

应用场景

  • • 文件下载服务的速度控制
  • • 视频流媒体的带宽管理
  • • API接口的响应限速
